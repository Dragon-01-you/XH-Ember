## 1. 六条会改变决策的事实

### ① SAE Web 应用确实下线了（官方原文，A 级）
2025-12-30 发布《【产品变更】Serverless 应用引擎 SAE 产品 Web 应用功能下线通知》：
> 后续 Serverless Web 服务将由阿里云函数计算 FC 产品继续演进发展。
> SAE 将从 2026 年 1 月 30 日起，禁止创建新的 web 应用，直至最终下线。

→ 记忆里那个"平台给域名直接部署"的能力，**曾经存在，现在没了**，承接者是 FC。

### ② 阿里云学生 300 元无门槛券（本报告对我们最有价值的一条，A 级）
「云工开物」高校计划：完成学生认证（含**专科**）后，**每年可领 1 张 300 元无门槛优惠券**，
直接抵扣公共云产品，有效期 1 年。
→ 香港轻量约 24 元/月 ≈ 288 元/年，**一张券基本覆盖一年**。目标用户正是专科生。

### ③ 香港轻量的真实网络表现（C 级实测，但结论要反过来读）
- 电信：晚高峰 22:00 由 32 万 kbps 降至 6 万 kbps（报告写"降幅超 80%"）
- 移动：晚高峰保持 20 万+ kbps，最高 38 万 kbps
- 日本 Lightsail：湖南电信晚高峰 ping 70ms，**丢包 8%–10%**

**补判：6 万 kbps = 60 Mbps。** 报告用"降幅超 80%"描述，听起来吓人，但绝对值对个人小站完全够用。
**真正的风险是丢包**，它影响 SSH/交互式部署，不影响静态站访问。

### ④ Qoder Sites 的真实边界（A 级）
- 个人 **Free 版只支持静态网页**，不支持数据库与对象存储；Pro 及以上才支持 Agent App
- **不支持绑定外部自定义域名**，只能修改地址前缀（`*.<前缀>.qoder.zone`）
- 企业版（Teams/Enterprise）**禁止**向组织外分享或公开
- 限免额度**账号下所有站点合并计算**，高用量站点会被暂停公开访问
- 有 CLI + JSON（`qoder sites`），只读操作可脚本直调，写操作需 Agent 复述确认

→ 定位只能是"**几分钟看一眼**"，不能做正式承载。

### ⑤ 个人主体的备案服务类型限制（A 级，最狠的一条）
网宿科技备案填写规范：**开办主体为「个人」时，服务类型只能选「博客 / 个人空间」**；
经营性网站必须额外申请 ICP 经营许可证；不涉及交互需把"是否提供互联网交互服务"选"否"。

→ **大陆路径对"工具站 / 业务站"基本走不通**，只适合个人博客类。这条直接改变了路径权重。

### ⑥ 公安联网备案（A 级，之前漏了）
ICP 备案通过后，如为中国内地提供服务，须在**网站开通之日起 30 日内**登录
全国公安机关互联网站安全管理服务平台（beian.gov.cn）提交公安联网备案；
未办理可处**警告或停机整顿不超过 6 个月**。

## 2. 报告暴露的一条安全红线

Qoder CLI 提供 `--yolo` / `--dangerously-skip-permissions` / `--permission-mode bypass_permissions`
可以**跳过写操作的二次确认**。

→ 我们的产品**禁止使用这些标志**。否则 ADR-0006 的"机制层硬拦截"形同虚设。
这条要写成代码级约束，不只是文档约定。

## 3. 对产品定位的三条修正

1. **大陆路径降级。** 个人主体只能备案"博客/个人空间"，经营性要许可证。
   → 不再作为主路，只作为"个人博客类用户"的可选项。
2. **香港轻量升级为主路。** 免备案、不限制服务类型、学生券几乎覆盖成本、实测速度够用。
3. **Qoder Sites 明确为体验层。** 只做静态、免费、几分钟；不做正式承载（不支持数据库/自定义域名/有限额）。
