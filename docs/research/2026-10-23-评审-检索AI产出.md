# 评审：检索 AI 交回来的报告（2026-10-23 PDF，116 页）

## 一句话结论

**这不是报告，是检索过程的流水账，而且最后没有产出成品。** 只能当线索用，不能当依据。

## 为什么这么说（三条硬证据）

1. **它没有交出成品。** 文档最后一页（P115–116）写的是「最终回答」，内容却是模型的自言自语（"嗯，用户的需求很复杂…"）加上**重新输出了一遍检索计划**。也就是说：检索做了 100 页，最后停在"计划"这一步，没有摘要、没有产品总表、没有结论。
2. **它没有遵守自己收到的流程。** 提示词要求"先给 300 字检索计划，等确认后再展开"。它把计划放到了最后一页，等于跳过了确认门。
3. **约三成内容是跑题。** P105–P114 讲的是：边缘计算节点的负载均衡、边缘节点的数据持久化（IndexedDB + Redux-Persist）、OTA 升级、Prometheus 监控、Craigslist 诉 3Taps 版权案、翻墙是否违法。这些和"中国个人把项目部署到公网"没有关系。

## 它错的地方

**否认了 SAE Web 应用下线（P11–P15）。** 原文说"搜索结果未直接确认 SAE Web 应用功能已下线……建议核实信息来源是否准确"。
但官方公告是存在的（`https://www.aliyun.com/notice/117829`），外部完整市场报告也引用了它。
→ 这是"没搜到"被写成了"不存在"，属于方法论错误。

## 能用的部分（6 条，按价值排序）

1. **EdgeOne Pages 的区域规则（P15–P19）** —— 价值最高。
   - 加速区域含中国大陆时，只能用系统预览链接，**3 小时过期，超时返回 401**；
   - 绑定自定义域名后**解除 3 小时限制**，但大陆区域绑域名必须先 ICP 备案；
   - **不含中国大陆区域时，绑自定义域名免备案**，但大陆网络访问会返回 401。
   → 这等于给出了一条新候选：**腾讯云 EdgeOne Pages（非大陆区域）+ 自定义域名 = 免备案 + 长期公开**。

2. **个人主体 ICP 备案的材料清单（P98–P99）**：身份证正反面、手持证件照、手机号、邮箱、域名证书；部分省份另要居住证/暂住证、网站建设方案书；证件照禁复印件与截图，水印只能写"仅限 ICP 备案使用"。

3. **个人备案流程 6 步与耗时（P99–P102）**：服务商初审 1–3 工作日 → 短信核验 24 小时内 → 管局终审 3–20 工作日；总体 1–22 工作日，平均 18–25 天；一线城市 1–2 周。

4. **海外云对大陆个人的门槛（P91–P97）**：阿里云国际站**不接受**中国大陆居民身份证，建议去中国站；AWS 中国区**不支持个人账户**，只收营业执照；Azure 中国由世纪互联运营、需企业文件。
   → 这解释了为什么"海外路径"对个人来说基本只剩 Vercel / Cloudflare 这类不需要实名的静态托管。

5. **香港轻量价格区间（P38–P40）**：阿里云香港轻量约 25–336 元/月，另有 1C1G30M 81 元/年起的旧数据；腾讯云价格数据自相矛盾；华为云未找到。
   → 价格可信度只到 C 级，**支付方式一项完全没有查到**（原文自认"搜索结果未包含具体支付方式"）。

6. **国内访问速度的定性对比（P49–P50）**：Cloudflare Pages 节点最多但大陆节点需备案才启用；Vercel 走新加坡/日本；Netlify 近年变慢（有"3 秒"反馈）；GitHub Pages 最慢。全部为 C 级评测，无实测数据。

## 对我们定位的三个影响

1. **大陆路径可以留。** 个人主体确实能办 ICP，材料和流程都是公开的，平均 18–25 天。不是不能做，是慢。
2. **"海外"要重新定义。** 海外云的国际站不收大陆身份证、AWS 中国区不收个人账户。所以我们说的"海外"，实际只能是 **Vercel / Cloudflare 这类不需要实名的静态托管**，加上**从国内云厂商买的香港轻量**。
3. **多了一条候选路径**：腾讯云 EdgeOne Pages（非大陆区域）+ 自定义域名，免备案且能长期公开。要和 Cloudflare Pages 并列比较。

## 建议

不要再整份重跑（同样的提示词只会得到同样的流水账）。改成**定向补查**：只查上表里没答的 6 项，每项出一页，要求必须给官方链接或实测截图。

如果一定要重跑，提示词要加三条硬约束：
1. 先输出检索计划并停下，等确认；
2. 禁止出现六个平面之外的主题，跑题即作废；
3. 必须交出产品总表与反例章节，缺一项不算完成。
